YACM packages

The apt and dnf repository for YACM, the SSH, telnet and serial connection manager.

The .deb and .rpm packages on the release page add this repository when you install them, so apt upgrade or dnf upgrade bring new versions. To add it by hand instead:

Ubuntu 22.04+ and Debian 12+

sudo curl -fsSLo /usr/share/keyrings/yacm-packages.asc https://pkg.yacm.app/yacm.asc
sudo curl -fsSLo /etc/apt/sources.list.d/yacm.sources https://pkg.yacm.app/yacm.sources
sudo apt update && sudo apt install yacm

Fedora

sudo curl -fsSLo /etc/yum.repos.d/yacm.repo https://pkg.yacm.app/yacm.repo
sudo dnf install yacm

Signing key

The repository and the .rpm packages are signed with "YACM packages <support@yacm.app>", fingerprint 9C9A 2975 7D17 AFD5 51B6 0BFB 1FA9 9EB2 609B DAAF. The packages are built by the release workflow and checked against their build provenance before they are published here (how).
